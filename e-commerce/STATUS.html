Recently completed#

  • payment-service: one payment per order, provider calls outside transactions, void requests that always win, reconciler that voids late provider successes (proved with a real late-success race), append-only audit trail.

  • order-service: checkout saga with every compensation path, idempotency keys, crash recovery, monthly partitions with id-based pruning, JWT-secured API, circuit breakers and retries; container tests caught and fixed a millisecond/microsecond mismatch between order ids and partition keys.

  • inventory-service: no-overselling reservations, expiry job, outbox relay, cancellation safety net, REST API with problem details; tests prove 50 concurrent orders for 10 units reserve exactly 10.

  • Walkthrough engine: animated diagrams, light / medium / dark themes, narration on/off with a female voice, automated step check.
  • Repository structure: e-commerce/ self-contained, with design/ (system), services/ (independent projects), deploy/, tests/ and tools/.

In progress#

  • cart-service: Redis carts for guests and customers, re-pricing through catalog with a degraded fallback, checkout snapshot, cart clearing on OrderConfirmed.
  • System, module and service diagrams (design document 11).
