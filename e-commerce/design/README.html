E-commerce platform README.md

Design documents#

The detailed design of the e-commerce platform. Start with the specification for requirements and the reasons behind the design, then read these documents in order.

# Document What it contains
1 High-level design System context, containers, layers, request and event paths, technology map
2 Data-flow diagrams DFD level 0, level 1 and level 2 for checkout; data stores; trust boundaries
3 Deployment design Kubernetes topology across zones, networking, CI/CD pipeline, environments, local stack
4 Database design ER diagrams, tables, indexes, partitioning, Cassandra tables, Redis keys, OpenSearch mapping, retention
5 Sequence diagrams Checkout (happy path and every failure), cancellation, outbox relay, idempotent consumer, sign-in, uploads, search indexing, reviews
6 Flow diagrams Checkout decisions, saga recovery, reservation expiry, rate limiting, consumer retry and dead letters, cache-aside
7 State diagrams Order, saga step, payment and reservation state machines
8 Class and UML diagrams Domain models, ports and adapters, component and package diagrams
9 API catalogue Every public and internal endpoint with request and response shapes
10 Event catalogue Every event, topic, key, producer, consumer and payload
11 Low-level design per service Each service keeps its own design in services/<service>/design/README.md (links below)
12 Architecture decision records One record per significant decision
